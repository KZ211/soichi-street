# Soichi Street

Landing de demo para Soichi Street, taller de chapa y pintura en Presidente Derqui, Pilar. Se arma el pedido de presupuesto marcando las partes del auto y se envía por WhatsApp.

Astro + React (solo el armador de presupuesto), pnpm, Node desde `mise.toml`.

```sh
pnpm install
pnpm dev      # http://localhost:4321
pnpm build
```

- Contenido: `src/data/site.ts` (servicios, trabajos, etapas del proceso, WhatsApp).
- Fotos: `src/assets/`, sacadas de las publicaciones de @soichi_street. Son para la demo; publicar requiere su permiso.
- Producto y diseño: `PRODUCT.md`, `DESIGN.md`.

A confirmar con el dueño antes de publicar: horarios, precios, dirección exacta, dominio y permiso de uso de las fotos.
